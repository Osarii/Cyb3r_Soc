# 21st.dev / Uiverse — nota de uso

Se revisaron ambos catálogos como fuente de técnicas e inspiración.

Para este paquete final no se copiaron:
- previews,
- screenshots,
- GIFs,
- videos,
- ni componentes de terceros.

Motivo: las referencias de Cyb3r_Soc requieren arte específico y el objetivo es reducir dependencias de runtime. La onda de partículas y la neblina se generaron como assets propios optimizados; no se añadió Three.js/WebGL al proyecto.

Enlaces revisados:
- https://21st.dev/
- https://uiverse.io/

Esto deja el paquete autocontenido y evita introducir dependencias o media externa innecesaria.
