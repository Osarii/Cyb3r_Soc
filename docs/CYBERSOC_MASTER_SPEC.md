# CyberSOC Master Specification

CyberSOC is a safe, educational frontend simulation of a modern Security Operations Center. It never attacks, scans, exploits, or connects to real targets. All IPs use documentation ranges and all events remain local to the application.

The product language combines restrained cyberpunk, spatial technology, military interfaces, and premium enterprise software. Purple is the primary interface color; red is reserved for critical states. Components use matte dark surfaces, fine borders, subtle depth, and faceted geometry. Accessibility, keyboard navigation, reduced motion, and responsive layouts are required.

Core flow: boot once per session, enter Dashboard, open Threat Map, select a simulated scenario, arm the console, open its safety cover, manually confirm, observe countdown and trajectory, create an incident, contain it, run mitigation to 100%, resolve it, and let CyberAI summarize the result.

Data is fictitious. Browser storage is limited to initialization, preferences, and simulation state.
